###Database Management Systems :
*Overview*
Also called DBMS
A software system to facilitate the creation and maintenance of a computerized database
Database Software = DBMS + Applications
Database System = Database + Software
*DBMS for the course: Oracle Database*


*Typical DBMS functionality*
] *Define a database* in terms of data types, structures, and constraints
] *Construct or load the database* on secondary storage
] *Manipulate the database* through queries reports, insertion, deletion
] *Concurrent processing and sharing* by a set of users and programs while keeping data valid
] *Protection or security measures* to prevent unauthorised
